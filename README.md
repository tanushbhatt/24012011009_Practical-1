# Practical-1: Kotlin Programming Concepts

This practical demonstrates various fundamental programming concepts in **Kotlin**, including variables, type conversion, user input, control flow, functions, recursion, arrays, ArrayLists, classes, constructors, operator overloading, and matrix operations.

## 1.1 Store & Display Values in Different Variables

Create and display variables using different Kotlin data types:

- Integer (`Int`)
- Double (`Double`)
- Float (`Float`)
- Long (`Long`)
- Short (`Short`)
- Byte (`Byte`)
- Character (`Char`)
- Boolean (`Boolean`)
- String (`String`)

## 1.2 Type Conversion

Demonstrate type conversion between different data types:

- Integer → Double
- String → Integer
- String → Double

## 1.3 Scan Student's Information and Display All the Data

Take student information as input and display it.

Information includes:

- Student Name
- Enrollment Number
- Branch
- Other student details

## 1.4 Check Odd or Even Numbers

Determine whether a given number is **odd or even** using control flow inside the `println()` method.

## 1.5 Display Month Name

Use a Kotlin **`when` expression** to display the month name based on the month number entered by the user.

For example:

```text
1 → January
2 → February
3 → March
...
12 → December
```

## 1.6 User-Defined Function

Create a user-defined function to perform basic arithmetic operations on two numbers:

- Addition
- Subtraction
- Multiplication
- Division

## 1.7 Factorial Calculation with Recursion

Calculate the factorial of a number using a **recursive function**.

Example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

## 1.8 Working with Arrays

Explore different Kotlin array operations and methods, including:

- `Arrays.deepToString()`
- `contentDeepToString()`
- `IntArray.joinToString()`

Also use different loop and range operations such as:

- `range`
- `downTo`
- `until`

The practical also demonstrates sorting an integer array:

- Without using built-in sorting functions
- Using built-in sorting functions

## 1.9 Find Maximum Number from ArrayList

Create an `ArrayList` of integers and find the **maximum number** from the list.

## 1.10 Class and Constructor Creation

Create a `Car` class with properties such as:

- Type
- Model
- Price
- Owner
- Miles Driven

Implement functions to:

- Get car information
- Find the original car price
- Calculate the current car price
- Display car information

This practical demonstrates **classes and constructors in Kotlin**.

## 1.11 Operator Overloading and Matrix Operations

Create a `Matrix` class and demonstrate **operator overloading** for:

- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication

The `Matrix` class also overloads the `toString()` function to provide customized matrix output.

### Operators Used

```text
+  → Matrix Addition
-  → Matrix Subtraction
*  → Matrix Multiplication
```

## Concepts Covered

Through this practical, the following Kotlin concepts are demonstrated:

- Variables and Data Types
- Type Conversion
- User Input
- Conditional Statements
- `when` Expression
- Functions
- Recursion
- Arrays
- ArrayList
- Loops and Ranges
- Sorting
- Classes
- Constructors
- Operator Overloading
- Matrix Operations
- `toString()` Overriding

- **Language:** Kotlin
- **IDE:** Android Studio / IntelliJ IDEA
- **Platform:** Kotlin/JVM
